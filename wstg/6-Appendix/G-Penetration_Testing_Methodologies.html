Metodologías de pruebas de penetración

Este apéndice documenta metodologías y marcos de trabajo establecidos para las pruebas de penetración. Estos estándares proporcionan orientación detallada sobre los procedimientos de prueba, las fases y los informes. El marco de pruebas de OWASP (Sección 3) describe cuándo probar y qué técnicas aplicar. Este apéndice cataloga el cómo: metodologías estructuradas a las que los profesionales pueden recurrir al realizar compromisos formales de pruebas de penetración.

OWASP Testing Guides

El proyecto OWASP mantiene guías de pruebas para distintos tipos de aplicaciones:

  • OWASP Web Security Testing Guide - aplicaciones web y servicios web
  • OWASP Mobile Security Testing Guide - aplicaciones iOS y Android
  • OWASP Firmware Security Testing Methodology - sistemas embebidos y firmware
  • OWASP AI Testing Guide - aplicaciones de IA y de Large Language Models (LLM)

PCI Penetration Testing Guide

El requisito 11.3 de PCI DSS exige pruebas de penetración para las organizaciones que manejan datos de tarjetas de pago. La guía de PCI cubre:

  • Componentes y cualificaciones de las pruebas de penetración
  • Metodologías de prueba aceptadas por la industria
  • Cobertura de los entornos de datos de titulares de tarjetas (CDE) y de los sistemas críticos
  • Requisitos de pruebas externas e internas
  • Pruebas a nivel de aplicación y a nivel de red
  • Validación del alcance y procedimientos de prueba

Penetration Testing Framework

El Penetration Testing Framework (PTF) fue un recurso integral para las pruebas de penetración prácticas, pero el proyecto ya no se mantiene activamente. Como referencia histórica, categorizaba las actividades de pruebas de penetración en reconocimiento de red (footprinting), descubrimiento, enumeración, evaluación de vulnerabilidades y áreas de prueba especializadas (inalámbrico, VoIP, seguridad física). Los profesionales actuales deben consultar los marcos activos enumerados anteriormente (NIST 800-115, OSSTMM) y las OWASP Testing Guides para obtener orientación vigente.

Technical Guide to Information Security Testing and Assessment

NIST SP 800-115 proporciona una referencia técnica para las pruebas y la evaluación de la seguridad, que abarca:

  • Técnicas de revisión (revisión de documentos, revisión de código, pruebas de seguridad)
  • Técnicas de identificación y análisis de objetivos (reconocimiento activo/pasivo)
  • Técnicas de validación de vulnerabilidades en los objetivos (análisis dinámico y estático)
  • Planificación y ejecución de la evaluación de seguridad
  • Actividades posteriores a las pruebas (análisis e informes)

El documento relacionado NIST SP 800-218 (Secure Software Development Framework) proporciona una orientación más amplia sobre prácticas de desarrollo seguro a lo largo del SDLC.

Open Source Security Testing Methodology Manual

OSSTMM es una metodología integral para probar la seguridad operativa en ubicaciones físicas, flujos de trabajo y sistemas técnicos. Cubre:

  • Análisis de seguridad y evaluación de riesgos
  • Pruebas de seguridad humana (ingeniería social, concienciación)
  • Pruebas de seguridad física
  • Pruebas de seguridad inalámbrica y de telecomunicaciones
  • Pruebas de seguridad de redes de datos
  • Procedimientos de cumplimiento y auditoría
  • Informes mediante el marco STAR (Security Test Audit Report)

OSSTMM se utiliza a menudo como referencia para las pruebas de cumplimiento y la evaluación de riesgos operativos, complementando las pruebas técnicas de vulnerabilidades.

Adversary Emulation and MITRE ATT&CK

Además de las metodologías estructuradas de pruebas de penetración, los ejercicios de emulación de adversarios enmarcan las pruebas en torno a técnicas y tácticas de ataque reales. MITRE ATT&CK es una base de conocimiento de acceso global sobre tácticas y técnicas de adversarios derivada de la observación del mundo real. Los equipos de seguridad y los red teams utilizan cada vez más ATT&CK para:

  • Estructurar los compromisos de pruebas de penetración en torno a rutas de ataque realistas
  • Priorizar el modelado de amenazas y las inversiones en defensa
  • Diseñar procedimientos de ingeniería de detección y de búsqueda de amenazas (threat hunting)

ATT&CK complementa las metodologías tradicionales de pruebas de penetración enumeradas anteriormente al proporcionar una taxonomía común y una perspectiva centrada en el adversario, en lugar de una basada en fases o en herramientas.
