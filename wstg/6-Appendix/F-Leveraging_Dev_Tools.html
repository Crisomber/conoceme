F. Aprovechamiento de las herramientas de desarrollo

Este apéndice describe diversos detalles sobre el uso de la funcionalidad de las herramientas para desarrolladores (Developer Tools) del navegador como apoyo a las actividades de pruebas de seguridad.

Obviamente, la funcionalidad del navegador no sustituye a las herramientas DAST (Dynamic Application Security Testing), a las herramientas SAST (Static Application Security Testing) ni a la experiencia de un evaluador; sin embargo, puede aprovecharse para algunas actividades de prueba y para tareas relacionadas con la producción de informes.

Acceso a las Dev Tools

Abrir las Dev Tools puede lograrse de varias maneras.

  1. Mediante el atajo de teclado F12.
  2. Mediante el atajo de teclado ctrl + shift + i en Windows.
  3. Mediante el atajo de teclado cmd + option + i en Mac.
  4. Mediante el menú contextual del clic derecho en la página web y luego seleccionando Inspect en Google Chrome.
  5. Mediante el menú contextual del clic derecho en la página web y luego seleccionando Inspect Element en Mozilla Firefox.
  6. Mediante el menú de tres puntos ('kebab') en Google Chrome y luego seleccionando More Tools y después Developer Tools.
  7. Mediante el menú de tres líneas ('hamburguesa') en Mozilla Firefox y luego seleccionando Web Developer y después Toggle Tools.

NOTA: La mayoría de las instrucciones siguientes asumen que las Dev Tools ya están abiertas o activas.

Cambio de User-Agent

Pruebas relacionadas

  • Debilidades de la caché del navegador

Google Chrome

  1. Haz clic en el menú de tres puntos ('kebab') en el lado derecho del panel de Developer Tools, selecciona More tools y luego selecciona Network conditions.
  2. Desmarca la casilla "Select automatically".
  3. Selecciona el user agent en el menú desplegable o introduce un user agent personalizado


Figura 6.F-1: Funcionalidad de cambio de User-Agent en las Dev Tools de Google Chrome

Mozilla Firefox

  1. Navega a la página about:config de Firefox y haz clic en I accept the risk!.
  2. Introduce general.useragent.override en el campo de búsqueda.
  3. Busca general.useragent.override; si no ves esta preferencia, busca una que muestre un conjunto de botones de opción Boolean, Number, String, selecciona String y luego haz clic en el botón del signo más Add en la página about:config.
  4. Establece el valor de general.useragent.override con el User-Agent que necesites.


Figura 6.F-2: Funcionalidad de cambio de User-Agent en Mozilla Firefox

Después, haz clic en el botón del bote de basura Delete a la derecha de la preferencia general.useragent.override para eliminar la sustitución y volver al user agent por defecto.

Editar/reenviar peticiones

Pruebas relacionadas

  • Pruebas de autenticación
  • Pruebas de autorización
  • Pruebas de gestión de sesiones
  • Pruebas de inyección
  • Pruebas de lógica de negocio

Mozilla Firefox

  1. Selecciona la pestaña Network.
  2. Realiza cualquier acción en la aplicación web.
  3. Haz clic derecho en la petición HTTP de la lista y selecciona Edit and Resend.
  4. Realiza las modificaciones deseadas y haz clic en el botón Send.
  5. Haz clic derecho en la petición modificada y selecciona Open in New Tab.

Google Chrome

  1. Selecciona la pestaña Network.
  2. Realiza cualquier acción en la aplicación web.
  3. Haz clic derecho en la petición HTTP de la lista y selecciona Copy > Copy as fetch.
  4. Pega el código JavaScript proporcionado en la pestaña Console.
  5. Realiza las modificaciones necesarias y luego presiona enter para enviar la petición.

Edición de cookies

Pruebas relacionadas

  • Pruebas de autenticación
  • Pruebas de autorización
  • Pruebas de gestión de sesiones
  • Atributos de las cookies

Google Chrome

  1. Haz clic en la pestaña Application.
  2. Expande Cookies bajo el encabezado Storage.
  3. Selecciona el nombre de dominio correspondiente.
  4. Haz doble clic en la columna Value para editar el valor de cualquier cookie.

Nota: Las cookies se pueden eliminar una vez seleccionadas presionando la tecla delete, o desde el menú contextual del clic derecho.

Mozilla Firefox

  1. Haz clic en la pestaña Storage.
  2. Expande la sección Cookies.
  3. Selecciona el nombre de dominio correspondiente.
  4. Haz doble clic en la columna Value para editar el valor de cualquier cookie.

Nota: Las cookies se pueden eliminar una vez seleccionadas presionando la tecla delete, o con varias opciones del menú contextual del clic derecho.

Edición del almacenamiento local (Local Storage)

Pruebas relacionadas

  • Pruebas del almacenamiento del navegador

Google Chrome

  1. Haz clic en la pestaña Application.
  2. Expande Local Storage bajo el encabezado Storage.
  3. Selecciona el nombre de dominio correspondiente.
  4. Haz doble clic en la columna Value para editar el valor de cualquier cookie.
  5. Haz doble clic en la celda correspondiente para editar la Key o el Value.

Nota: Editar Session Storage o Index DB sigue esencialmente los mismos pasos.

Nota: Se pueden agregar o eliminar elementos desde el menú contextual del clic derecho.

Mozilla Firefox

  1. Haz clic en la pestaña Storage.
  2. Expande la sección Local Storage.
  3. Selecciona el nombre de dominio correspondiente.
  4. Haz doble clic en la celda correspondiente para editar la Key o el Value.

Nota: Editar Session Storage o Index DB sigue esencialmente los mismos pasos.

Nota: Se pueden agregar o eliminar elementos desde el menú contextual del clic derecho.

Deshabilitar CSS

Pruebas relacionadas

  • Manipulación de recursos del lado del cliente

General

Todos los navegadores principales admiten la manipulación de CSS aprovechando la Console de las Dev Tools y la funcionalidad de JavaScript:

  • Para eliminar todas las hojas de estilo externas: $('style,link[rel="stylesheet"]').remove();
  • Para eliminar todas las hojas de estilo internas: $('style').remove();
  • Para eliminar todos los estilos en línea: Array.prototype.forEach.call(document.querySelectorAll('*'),function(el){el.removeAttribute('style');});
  • Para eliminar todo el contenido de la etiqueta head: $('head').remove();

Deshabilitar JavaScript

Google Chrome

  1. Haz clic en el menú de tres puntos ('kebab') en el lado derecho de la barra de herramientas del desarrollador web y haz clic en Settings.
  2. En la pestaña Preferences, en la sección Debugger, marca la casilla Disable JavaScript.

Mozilla Firefox

  1. En la pestaña Debugger de las Dev Tools, haz clic en el botón del engranaje de configuración en la esquina superior derecha de la barra de herramientas del desarrollador.
  2. Selecciona Disable JavaScript en el menú desplegable (es un elemento de menú de activación/desactivación; cuando JavaScript está deshabilitado, el elemento del menú muestra una marca de verificación).

Codificación y decodificación

Pruebas relacionadas

  • Muchos (quizás incluso la mayoría de) los tipos de Pruebas de seguridad de aplicaciones web pueden beneficiarse de diversos tipos de codificación.

General

Todos los navegadores principales admiten la codificación y decodificación de cadenas de varias maneras aprovechando la Console de las Dev Tools y la funcionalidad de JavaScript:

  • Codificación base64: btoa("string-to-encode") y decodificación base64: atob("string-to-decode") - funciones integradas de JavaScript que se utilizan para codificar una cadena a base64 y decodificar una cadena desde base64.
  • Codificación de URL: encodeURIComponent("string-to-encode") y decodificación de URL: decodeURIComponent("string-to-decode") - codifica y decodifica la entrada proporcionada por el usuario que se utilizará como parte de una URL, y codifica todos los caracteres que tienen significados especiales en una URL, incluidos los caracteres reservados.
  • Codificación de URI: encodeURI() y decodificación de URI: decodeURI() son funciones utilizadas para codificar y decodificar un URI completo, como parámetros de consulta, segmentos de ruta o fragmentos, incluidos los caracteres especiales pero excluyendo los caracteres reservados como :/?#[]@!$'()*+,;= que tienen significados especiales en una URL.
