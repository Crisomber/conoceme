B. Recursos de herramientas de pruebas

Introducción

Este apéndice tiene como finalidad proporcionar una lista de herramientas comunes que se utilizan para las pruebas de aplicaciones web. No pretende ser una referencia completa de herramientas, y la inclusión de una herramienta aquí no debe interpretarse como un respaldo específico de esa herramienta por parte de OWASP.

La lista contiene únicamente herramientas que se pueden descargar y usar libremente (aunque pueden tener licencias que restrinjan su uso para actividades comerciales).

Pruebas web generales

Proxies web

  • ZAP
    • El Zed Attack Proxy (ZAP) es una herramienta de pruebas de penetración integrada y fácil de usar para encontrar vulnerabilidades en aplicaciones web. Está diseñada para ser utilizada por personas con un amplio rango de experiencia en seguridad y, como tal, es ideal para desarrolladores y evaluadores funcionales que son nuevos en las pruebas de penetración.
      • ZAP proporciona escáneres automatizados, así como un conjunto de herramientas que permiten encontrar vulnerabilidades de seguridad manualmente.
  • Burp Suite Community Edition
    • Burp Suite es un proxy interceptor para pruebas de seguridad. Permite interceptar y modificar todo el tráfico HTTP(S) que pasa en ambas direcciones, y puede trabajar con certificados TLS personalizados y con clientes que no reconocen proxies.
  • Telerik Fiddler
    • Fiddler es un proxy web interceptor orientado principalmente a desarrolladores más que a evaluadores de penetración, pero que aun así ofrece funcionalidad útil. También se engancha directamente a las API HTTP de Windows, lo que le permite interceptar el tráfico de algunos programas que no permiten configurar proxies personalizados.
  • Gori
    • Gori es un proxy interceptor manejado desde una interfaz de usuario de terminal (TUI), con pestañas para el historial, repeater y fuzzer, reproducción de control de acceso, JWT, análisis de tokens de sesión y pruebas fuera de banda. El mismo proyecto se puede automatizar mediante gori run y es accesible para herramientas de IA a través de un servidor de Model Context Protocol.

Extensiones de Firefox

  • Firefox HTTP Header Live
    • Permite ver las cabeceras HTTP de una página mientras se navega.
  • Firefox Multi-Account Containers
    • Crea múltiples contenedores, cada uno con sus propias cookies y sesiones aisladas. Es útil para probar el control de acceso entre distintos usuarios.
  • Firefox Web Developer
    • La extensión Web Developer añade diversas herramientas para desarrolladores web al navegador.

Extensiones de Chrome

  • Chrome Web Developer
    • La extensión Web Developer añade al navegador un botón en la barra de herramientas con diversas herramientas para desarrolladores web. Es el port oficial de la extensión Web Developer para Chrome.
  • Cookie Editor
    • Una extensión de navegador potente y fácil de usar que permite crear, editar y eliminar rápidamente las cookies de la pestaña actual. Es útil para desarrollar, probar o gestionar cookies manualmente.

Descubrimiento de contenido

  • Gobuster
  • Waybackurls
    • Waybackurls obtiene todas las URL conocidas por la Wayback Machine para un dominio determinado, lo que es útil para el reconocimiento.
    • Uso:
waybackurls example.com
  • GAU (Get All URLs)
    • GAU recopila URL de múltiples archivos públicos, incluidos la Wayback Machine y Common Crawl.
    • Uso:
gau example.com
  • Unfurl
    • Unfurl extrae subdominios, rutas y parámetros de las URL para un análisis más profundo.
    • Uso:
unfurl "https://example.com/page?query=123"

Detección de la superficie de ataque

  • OWASP Noir
    • Noir analiza el código fuente para listar endpoints, métodos y parámetros de muchos lenguajes y frameworks. Genera texto plano, JSON, OpenAPI o comandos curl, y puede reproducir los endpoints descubiertos a través de ZAP o Burp Suite.
  • OWASP Attack Surface Detector
    • El Attack Surface Detector utiliza análisis estático de código para identificar endpoints y parámetros, y está disponible como herramienta de línea de comandos y como plugins para ZAP y Burp Suite.

Herramientas de automatización de navegadores

Las herramientas de automatización de navegadores se utilizan para validar la funcionalidad de las aplicaciones web. Algunas siguen un enfoque basado en scripts y suelen hacer uso de un framework de pruebas unitarias para construir suites y casos de prueba. La mayoría, si no todas, pueden adaptarse para realizar pruebas específicas de seguridad además de pruebas funcionales.

Herramientas de código abierto

  • HtmlUnit - HtmlUnit es un navegador sin interfaz gráfica para programas Java. Modela documentos HTML y proporciona una API para invocar páginas, rellenar formularios, hacer clic en enlaces e interactuar con JavaScript y con bibliotecas AJAX complejas. Puede simular Chrome, Firefox o Edge según la configuración, y se utiliza normalmente para pruebas automatizadas o web scraping. HtmlUnit también puede usarse como un navegador compatible con Selenium mediante el htmlunit-driver. La última versión estable es la 4.21.0 (org.htmlunit:htmlunit:4.21.0).
    • Repositorio de GitHub: HtmlUnit/htmlunit
  • Selenium
    • Framework de pruebas basado en JavaScript, multiplataforma, que proporciona una interfaz gráfica para crear pruebas.

Recursos en línea para comparar herramientas de pruebas de seguridad

Además de las herramientas individuales enumeradas en este apéndice, los profesionales a menudo necesitan recursos que les ayuden a comparar y evaluar herramientas de pruebas de seguridad en categorías como SAST, DAST, SCA y seguridad de API.

Los siguientes recursos de acceso gratuito ofrecen comparaciones seleccionadas y orientación para la evaluación.

Comparación de herramientas de AppSec Santa

  • AppSec Santa
    • Una comparación seleccionada de más de 160 herramientas de seguridad de aplicaciones en categorías como SAST, DAST, SCA, seguridad de API, seguridad de contenedores y más.

Analizador de cabeceras de seguridad

  • SecurityHeaders
    • Una herramienta gratuita en línea que analiza las cabeceras de respuesta HTTP y destaca las protecciones de seguridad ausentes o mal configuradas, como Content Security Policy, HSTS y X-Frame-Options.
