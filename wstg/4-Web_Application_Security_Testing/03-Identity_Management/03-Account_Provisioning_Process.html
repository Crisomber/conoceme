Proceso de aprovisionamiento de cuentas

ID
WSTG-IDNT-03

Resumen

El aprovisionamiento de cuentas representa una oportunidad para que un atacante cree una cuenta válida sin que se aplique el proceso adecuado de identificación y autorización.

Objetivos de la prueba

  • Verificar qué cuentas pueden aprovisionar otras cuentas y de qué tipo.

Cómo probar

Determinar qué roles pueden aprovisionar usuarios y qué tipo de cuentas pueden aprovisionar.

  • ¿Existe alguna verificación, revisión y autorización de las solicitudes de aprovisionamiento?
  • ¿Existe alguna verificación, revisión y autorización de las solicitudes de desaprovisionamiento?
  • ¿Puede un administrador aprovisionar a otros administradores o solo usuarios?
  • ¿Puede un administrador u otro usuario aprovisionar cuentas con privilegios mayores que los suyos?
  • ¿Puede un administrador o usuario desaprovisionarse a sí mismo?
  • ¿Cómo se gestionan los archivos o recursos que pertenecían al usuario desaprovisionado? ¿Se eliminan? ¿Se transfiere el acceso?

Ejemplo

En WordPress, solo se requieren el nombre y la dirección de correo electrónico de un usuario para aprovisionarlo, como se muestra a continuación:

El desaprovisionamiento de usuarios requiere que el administrador seleccione los usuarios que se van a desaprovisionar, elija Eliminar en el menú desplegable (marcado con un círculo) y luego aplique esta acción. Después, al administrador se le presenta un cuadro de diálogo que pregunta qué hacer con las entradas del usuario (eliminarlas o transferirlas).
