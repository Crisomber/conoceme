    Guía de pruebas de seguridad web

    El OWASP Web Security Testing Guide (WSTG) es la referencia mundial para evaluar la seguridad de aplicaciones web: cómo planear una prueba, qué revisar y cómo comprobar cada tipo de vulnerabilidad, desde la recopilación de información hasta la inyección SQL, la gestión de sesiones o las APIs.

    Aquí está la guía completa traducida al español, capítulo por capítulo. Usa el índice para moverte o el buscador para ir directo a una prueba por su nombre o su ID.
