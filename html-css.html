1 · HTML: etiquetas y atributos

La estructura de una página web: qué es una etiqueta, cómo se anidan y qué atributos llevan.

1. La etiqueta básica

Una etiqueta (tag) marca dónde empieza y termina un elemento: <p>texto</p>. La mayoría tiene apertura y cierre; unas pocas, como <img>, no llevan cierre.

EtiquetaPara qué sirve
<html>Envuelve todo el documento
<head>Metadata: título, enlaces a CSS (no se ve en pantalla)
<body>Todo el contenido visible
<h1> … <h6>Títulos, de más a menos importante
<p>Párrafo de texto
<a>Enlace a otra página
<img>Imagen
<ul> / <li>Lista y cada uno de sus elementos

2. Atributos

Van dentro de la etiqueta de apertura, con la forma nombre="valor". Le dan información extra al elemento.

AtributoSe usa enPara qué
href<a>A dónde lleva el enlace
src<img>Ruta del archivo de imagen
alt<img>Texto alternativo (accesibilidad, SEO)
classcualquieraConecta el elemento con reglas CSS
idcualquieraIdentificador único en la página

<img src="foto.jpg" alt="Una foto de la playa"> — siempre agrega alt, lo leen los lectores de pantalla.

3. Bloque vs en línea

¿Qué es?¿Corta línea?Ejemplos
BloqueCaja que ocupa todo el ancho disponibleSí, empieza en línea nuevadiv, p, h1, section, ul, li
En líneaCaja que solo ocupa su propio contenidoNo, sigue en la misma líneaspan, a, strong, em
💡 Truco: si necesitas estilizar solo una palabra en medio de una oración sin romper la línea, usa span. Si necesitas una caja independiente, usa div.

4. Anidado (nesting)

Las etiquetas se cierran en el orden inverso en que se abrieron, como paréntesis: la última que abre es la primera que cierra.

<p><strong>Texto</strong></p> <p><strong>Texto</p></strong>

    2 · CSS: selectores y el modelo de caja

    Cómo escribir una regla CSS, cómo apuntarla a un elemento concreto, y cómo se mide el espacio de cada caja.

    1. La forma de una regla CSS

    Toda regla CSS tiene esta forma:

    selector { propiedad: valor; propiedad: valor; }

    • Selector: a qué elementos aplica.
    • Propiedad: qué característica cambias (color, tamaño, espacio…).
    • Valor: a qué la cambias.

    .boton { color: red; } .boton { color = red }

    2. Selectores: etiqueta, clase e id

    TipoSintaxisAfecta a
    Etiquetap { }Todos los <p> de la página
    Clase.tarjeta { }Todo elemento con class="tarjeta" (puede repetirse)
    Id#menu { }El único elemento con id="menu"
    💡 Usa clases para reutilizar estilo en varios elementos. Usa id solo para algo único de verdad en toda la página (como un ancla de navegación).

    3. El modelo de caja

    Todo elemento HTML es, para CSS, una caja rectangular con cuatro capas, de adentro hacia afuera:

    CapaQué esPropiedad CSS
    ContentEl contenido mismo (texto, imagen)width / height
    PaddingEspacio entre el contenido y el bordepadding
    BorderLa línea que rodea la cajaborder
    MarginEspacio fuera del borde, hacia otras cajasmargin

    .caja { padding: 10px; border: 1px solid black; margin: 20px; }

    4. Vincular el CSS al HTML

    El CSS vive aparte y se conecta con una etiqueta en el <head>:

    <link rel="stylesheet" href="estilos.css">

    Luego, cualquier elemento con class="tarjeta" en el HTML recibe automáticamente lo que diga .tarjeta { } en ese CSS.

      3 · Diseño responsive y Flexbox

      Que tu página se vea bien tanto en el celular como en una pantalla grande.

      1. ¿Qué es diseño responsive?

      Es que el mismo HTML se adapte al tamaño de pantalla de quien lo ve, sin necesitar una versión distinta para móvil y otra para escritorio.

      <meta name="viewport" content="width=device-width, initial-scale=1"> — sin este meta tag en el <head>, el celular muestra la página como si fuera de escritorio y luego la achica.

      2. Media queries

      Son reglas CSS que solo aplican bajo cierta condición de pantalla:

      @media (max-width: 600px) { .columna { flex-direction: column; } }

      @media (max-width: 600px) { } @media screen 600px { }

      3. Flexbox básico

      Activas flexbox en el contenedor (el padre), no en los elementos hijos:

      .contenedor { display: flex; }

      PropiedadEje que controlaValores comunes
      justify-contentHorizontal (principal)flex-start, center, space-between
      align-itemsVertical (cruzado)flex-start, center, stretch

      4. flex-wrap

      Por defecto, flexbox intenta meter todo en una sola línea y encoge los elementos. Con flex-wrap: wrap, los que no caben pasan a la siguiente línea en vez de aplastarse.

      💡 Combo típico de una barra de tarjetas responsive: display: flex; flex-wrap: wrap; gap: 16px;
