🧠 Fundamentos de programación

1 · Variables y tipos de datos

Qué es una variable, cómo se declara y los tipos de datos más básicos.

1. ¿Qué es una variable?

Una variable es como una caja con una etiqueta: le pones un nombre y adentro guardas un valor que puedes usar o cambiar más adelante.

  • El nombre de una variable no puede empezar con un número: let edad2 = 25; let 2edad = 25;
  • Tampoco puede tener espacios: se suele escribir en camelCase: let miEdad = 25; let mi edad = 25;

2. Declarar y asignar

Palabra clave¿Para qué sirve?
letVariable que sí va a cambiar de valor
constVariable que NO va a cambiar (constante)
varForma antigua de declarar; hoy se evita

Declarar y asignar en un solo paso: let edad = 25;

3. Tipos de datos básicos

TipoEjemplo
Texto (string)"Hola mundo"
Número (number)25
Booleano (boolean)true / false

El texto siempre va entre comillas, aunque parezca un número: "25" es texto, no número.

4. Operadores aritméticos

OperadorNombreEjemplo
+Suma5 + 3 → 8
-Resta5 - 3 → 2
*Multiplicación5 * 3 → 15
/División6 / 3 → 2
%Módulo (resto)7 % 2 → 1
💡 El símbolo % no es "porcentaje" aquí: te da el resto de una división. Sirve mucho para saber si un número es par: n % 2 === 0.

    2 · Condicionales

    Cómo hacer que el código tome decisiones según una condición.

    1. if / else

    if (condición) { ... } else { ... } ejecuta un bloque u otro según si la condición es verdadera o falsa.

    TipoForma
    Si se cumpleif (edad >= 18) { ... }
    Si NO se cumpleelse { ... }

    Los paréntesis ( ) son obligatorios para la condición, y las llaves { } para el bloque de código: if x > 5 then

    2. else if (varias condiciones)

    Para encadenar más de dos caminos usamos else if:

    if (nota >= 90) { "A" } else if (nota >= 60) { "B" } else { "C" }

    3. Operadores de comparación

    OperadorSignificado
    ==Igual a
    !=Diferente de
    >Mayor que
    <Menor que
    >=Mayor o igual que
    <=Menor o igual que

    4. Operadores lógicos

    OperadorSignificadoEjemplo
    &&Y (ambas deben ser verdaderas)true && false → false
    ||O (al menos una verdadera)true || false → true
    !No (invierte el valor)!true → false
    💡 && es exigente: necesita que TODO sea verdadero. || es flexible: se conforma con que UNO solo lo sea.

      3 · Bucles y funciones

      Cómo repetir código con bucles y cómo agruparlo en funciones reutilizables.

      1. Bucle for

      for (let i = 0; i < 5; i++) { ... } repite el código mientras la condición sea verdadera, cambiando un contador en cada vuelta.

      ParteQué hace
      let i = 0Valor inicial del contador
      i < 5Condición de parada: sigue mientras sea verdadera
      i++Qué cambia en cada vuelta (suma 1)

      2. Bucle while

      while (condición) { ... } repite el código mientras la condición sea verdadera, sin un contador fijo de antemano.

      forwhile
      Sabes de antemano cuántas vueltas dasSolo sabes cuándo parar
      💡 Si la condición de un while nunca se vuelve falsa, el programa queda en un bucle infinito.

      3. Funciones

      Una función agrupa código para reutilizarlo sin copiarlo y pegarlo varias veces: function saludar(nombre) { return "Hola " + nombre; }

      4. Parámetros y return

      TérminoQué es
      ParámetroEl nombre que recibe la función (nombre en el ejemplo de arriba)
      ArgumentoEl valor real que le pasas al llamarla: saludar("Ana")
      returnLo que la función entrega como resultado

      Sin return, una función no entrega nada: function doble(n) { return n * 2; } function doble(n) { n * 2; }
