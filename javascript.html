1 · Variables and functions

Cómo guardar datos en una variable y cómo empaquetar código reutilizable en una función.

1. let y const (y por qué ya no se usa var)

Palabra clave¿Se puede reasignar?¿Respeta el bloque { }?
letSíSí
constNoSí
var (antiguo)SíNo — se "escapa" del bloque
  • Usa const por defecto: avisa si accidentalmente intentas cambiar algo que no debería cambiar.
  • Usa let solo cuando sí necesitas reasignar el valor más adelante (por ejemplo, un contador).
  • var casi no se usa hoy: no respeta el alcance de bloque, lo que puede causar errores difíciles de rastrear.

const nombre = "Ana"; let edad = 25; edad = 26;

var nombre = "Ana"; // evita var en código nuevo

2. Tipos de datos

TipoEjemplotypeof

3. Funciones

Una función empaqueta código para reutilizarlo. La forma clásica:

function suma(a, b) { return a + b; }

function suma(a, b) { a + b } // falta el return

4. Arrow functions

Son una forma más corta de escribir funciones, muy usada en JavaScript moderno:

const suma = (a, b) => a + b;

const suma = (a, b) -> a + b; // esa flecha no existe en JS

💡 Si la función solo tiene un return, puedes omitir las llaves { } y la palabra return, como en el ejemplo de arriba.

    2 · The DOM

    Cómo JavaScript lee y cambia lo que se ve en la página.

    1. Qué es el DOM

    El DOM (Document Object Model) es la representación de tu HTML como un árbol de elementos que JavaScript puede leer y modificar. Cuando JS "cambia la página", en realidad está cambiando el DOM, y el navegador vuelve a dibujar lo que cambió.

    2. querySelector y querySelectorAll

    MétodoQué devuelveEjemplo
    document.querySelector(sel)El primer elemento que coincidedocument.querySelector(".card")
    document.querySelectorAll(sel)Todos los que coinciden (una lista)document.querySelectorAll("li")
    • El selector es el mismo que usarías en CSS: "h1", ".card" (clase), "#titulo" (id).
    • Si no encuentra nada, querySelector devuelve null, no da error.

    3. Leer y cambiar texto y atributos

    Propiedad / métodoPara qué sirve
    elemento.textContentLee o cambia el texto visible (sin interpretar HTML)
    elemento.innerHTMLLee o cambia el contenido interpretando etiquetas HTML
    elemento.getAttribute("href")Lee el valor de un atributo
    elemento.setAttribute("href", "...")Cambia el valor de un atributo
    💡 Si el texto viene de un usuario (un formulario, por ejemplo), usa textContent en vez de innerHTML — evita que alguien meta HTML o scripts no deseados.

    4. Crear elementos

    const li = document.createElement("li"); li.textContent = "Nuevo"; lista.append(li);

    lista.append("Nuevo"); // falta crear el elemento, eso solo agrega texto suelto

      3 · Events

      Cómo hacer que tu página reaccione a lo que hace el usuario.

      1. addEventListener

      boton.addEventListener("click", function() { alert("¡Hola!"); });

      • Primer argumento: el nombre del evento, como string ("click").
      • Segundo argumento: la función que se ejecuta cuando pasa ese evento.

      2. Eventos comunes

      EventoCuándo se dispara
      clickAl hacer clic en el elemento
      submitAl enviar un formulario (<form>)
      inputCada vez que el usuario escribe en un campo
      keydownAl presionar una tecla

      3. event.target

      La función que pones en addEventListener recibe un objeto (normalmente llamado e o event) con información de lo que pasó. e.target es el elemento exacto que disparó el evento — muy útil cuando el mismo listener está en varios elementos.

      function manejar(e) { console.log(e.target.textContent); }

      4. preventDefault

      Algunos eventos tienen un comportamiento por defecto del navegador — por ejemplo, enviar un <form> recarga la página. e.preventDefault() evita ese comportamiento, para poder manejarlo tú mismo con JavaScript.

      formulario.addEventListener("submit", function(e) { e.preventDefault(); });

      💡 Sin preventDefault(), un formulario recarga la página al enviarse — y pierdes cualquier estado que tuvieras en JavaScript.
